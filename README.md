# Evolutionary Algorithm for Training an MLP Controller for Spacecraft Landing

## Overview
This project applies an Evolutionary Algorithm (EA) to train a Multilayer Perceptron (MLP) controller for spacecraft landing.

## Technologies Used
- Python / Java
- Neural Networks
- Evolutionary Algorithms
- Computational Intelligence

## Features
- Tournament Selection
- Uniform Crossover
- Gaussian Mutation
- Elitist Replacement

## Results
The mutation rate of 0.05 achieved the best overall performance and generalization.
